# MIMO 个人学习辅助 Agent
基于小米 MIMO 大模型打造的个人学习辅助智能体，用于整理零散学习笔记、自动梳理知识体系、识别薄弱知识点、生成针对性练习题，纯个人学习非商业用途。

## 功能特点
- 整理零散学习笔记，自动生成结构化知识图谱
- 智能识别个人薄弱知识点
- 自动生成复习计划与针对性练习题
- 基于小米 MIMO API 接口调用-基于小米MIMO API接口调用
